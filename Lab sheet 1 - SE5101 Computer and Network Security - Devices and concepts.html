01 · Devices

Core Networking Hardware

Each device below operates primarily at a specific OSI layer. Knowing the layer tells you what the device "reads" to make its decisions — MAC address, IP address, or just electrical signal. Watch each animation to see what the device actually does to traffic.

Repeater

L1 · Physical

Regenerates a weakening signal so it can travel further without losing quality — a weak wave in, a clean strong wave out.

Extends distance

Hub

L1 · Physical

A dumb multiport repeater — one message in gets flooded out of every other port, whether that node needs it or not.

Broadcasts to all

Modem

L1 · Physical

Converts digital signals to analog (and back) so data can ride telephone, cable, or fiber lines to the ISP.

WAN edge

Switch

L2 · Data Link

Learns each port's MAC address and forwards frames only to the intended port — no needless flooding like a hub.

Targeted delivery

Bridge

L2 · Data Link

Filters traffic between two segments using MAC addresses — local chatter (red) stays local, real cross-segment traffic (amber) passes through.

Segment filter

Wireless Access Point

L2 · Data Link

Bridges wireless clients (802.11) onto the wired LAN — broadcasting an SSID and converting radio frames to wired frames.

Wi-Fi entry point

Router

L3 · Network

Forwards packets between two different networks using IP addresses and a routing table — the boundary between LAN and WAN.

Inter-network

Firewall

L3–L7

Filters traffic against rules — ports, IPs, protocols, or application content — enforcing a security boundary between zones.

Security control

Patch Panel

L1 · Physical

A fixed passive panel of ports terminating cable runs, letting technicians re-patch connections without redoing wall wiring.

Cable management

Network Interface Card (NIC)

L1–L2

The hardware inside an endpoint providing its physical connection and unique MAC address — the blinking light is its link activity.

Endpoint hardware

Load Balancer

L3–L4

Distributes incoming requests across multiple servers in turn, improving availability and preventing any one server overloading.

Availability

Proxy Server

L7 · Application

Sits between clients and the internet, forwarding requests on their behalf — used for caching, content filtering, or anonymity.

Intermediary
02 · Topology

Physical & Logical Topologies

Physical topology is how devices are actually cabled together. Logical topology is how data actually travels, regardless of the physical layout. The two don't always match — a star-wired LAN, for instance, behaves logically like a bus.

Bus

Single backbone cable

All nodes share one backbone cable terminated at both ends. Cheap and simple, but one break disables the whole segment.

Low costSingle point of failure

Star

Central switch / hub

Every node connects to a central switch. The most common LAN topology — easy to manage, but the hub is a critical dependency.

Easy to troubleshootHub is critical

Ring

Closed loop

Each node connects to exactly two neighbors, forming a loop. Data travels in one (or both) directions around the ring.

Predictable flowBreak can down the loop

Mesh

Full / partial interconnect

Nodes connect directly to many (partial) or all (full) other nodes. Maximum redundancy at the cost of cabling complexity.

Highly redundantExpensive to scale

Tree

Hierarchical star-of-stars

Star networks linked through a root hub, forming parent/child branches — common in structured enterprise cabling.

Scalable, organizedRoot failure is costly

Hybrid

Combination of the above

Real-world networks mixing two or more topologies (e.g. mesh core + star edges) to balance cost, performance, and redundancy.

FlexibleComplex to design

04 · Lab Activity

Identification Exercise

Work through the steps below individually or in pairs, then complete the worksheet.

  1. Draw your home/ University networkSketch every device you can find between your laptop and the internet — endpoint, switch, router, modem, ISP.
  2. Label each deviceFor every device on your sketch, write its name and the OSI layer it primarily operates at (use the reference cards above).
  3. Classify the topologyLook at how the devices are physically cabled. Is it a star? A tree of stars? Note both the physical and logical topology.
  4. Justify the choiceWrite one sentence on why that topology suits the environment (cost, redundancy, size).
  5. Peer checkSwap sketches with a partner and verify each other's device layer labels.
